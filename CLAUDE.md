## Conventions worth not re-litigating

- **Generated/output files stay outside a framework's build inputs.**
  (`site/dashboard/*`, this pattern generally.) Keeps internal tooling from
  accidentally becoming public-facing.
- **Real data over mocks, always.** Every dashboard/board built here reads
  live from Airtable or the repo's own data files — no fabricated numbers,
  and empty states say plainly when something isn't tracked yet rather than
  inventing a plausible-looking value.
- **Secrets never get committed**, not even to this repo's history, not
  even "temporarily." Generate them, hand them to David in chat, verify the
  actual diff before every commit that touches a README or config file.
- **Airtable rate limits are per-base, not per-account.** LSFG Coaching and
  LSFG Video Pipeline don't compete with each other. `vision-board/lib/airtable.js`
  already retries on 429 with backoff.
- **This repo is public on GitHub.** Treat anything committed here as
  world-readable.
